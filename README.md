# Employee Performance & Workforce Analytics

## Project Overview

This project analyzes employee performance and workforce data to understand employee productivity, attendance, career progression, compensation, training, retention, and workforce risk.

The project demonstrates practical data analysis using PostgreSQL and Power BI, with a focus on HR analytics and business-oriented insights.

## Tools & Technologies

- SQL
- Power BI
- DAX
- Power Query
